# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-08-15

- Add read-only discovery and scoped audit modes.
- Freeze approved target UUIDs in a tamper-evident manifest.
- Require a verified canary before batch cleanup.
- Delete only closed leaf subagents through the Codex CLI.
- Verify database rows, spawn edges, rollout files, and main-thread byte prefixes.
- Require explicit skill invocation before starting the cleanup workflow.
- Mark compatibility as experimental because Codex's local schema and CLI can change.
